# Tabulka s početními operátory

| Operátor | Význam   | Příklad | Výsledek |
| -------- | -------- | ------- | -------- |
| +        | Sčítání  | a+b     | 13       |
| -        | Odčítání | a-b     | 7        |
| *        | Násobení | a*b     | 30       |
| /        | Dělení   | a/b     | 3 (celé) |
| %        | Modulo   | a%b     | 1        |
## Příklad
- Příklad počítá s proměnnýma:
	- <code>int a = 10</code>
	- <code>int b = 3</code>
