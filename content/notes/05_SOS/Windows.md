# Windows 11
## Hlavní novinky
- Nové Start menu uprostřed obrazovky
- Nový hlavní panel
- Snap Layouts a Snap Groups
- Widgety
- Microsoft Store nové generace
- Podpora Android aplikací (Amazon Appstore)
- Vylepšené virtuální plochy
- Herní technologie (AutoHDR, DirectStorage)
- Copilot (AI asistent)
## Minmální požadavky
- 4 GB RAM
- Podpora [[#UEFI]] a Secure Boot
- TPM - [[#TPM 2.0]]
- Grafika kompatibilní s DirectX 12
- HD, větší než 9 palců, 8 bitů na barevný kanál
- atd atd
### UEFI
- Moderní náhrada BIOSu
- rozhraní mezi OS a firmwarem
- Secure Boot
- rychlejší start systému
- lepší práce s velkými disky (GPT)
- možnost emulace BIOSu (CSM)
### TPM 2.0
- trusted platform module
- název specifikace, která popisuje zabezpečený kryptoprocesor, na který ukládá šifrovací klíče (windows hash)
## Přehled edicí
- **Home** - pro domácnosti
- **Pro**
	- malé a střední firmy
	- vzdálená plocha
	- připojení do Domény Windows - přihlašování doménovým účtem, ne lokálním
	- Active Directory - hromadná změna na několika počítačích 
- **Enterprise** - pro velké firmy
- **Education** - školní ekvivalent verze pro
- **Pro Education** - verze Pro pro školy
- **IoT Core** - pouze jádro, bez GUI, platforma pro Internet věcí
- **Pro for Workstations** - výkonné stanice
