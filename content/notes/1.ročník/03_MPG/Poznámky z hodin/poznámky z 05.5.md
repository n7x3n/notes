# Opakování

## Řízení cyklu
- <code>break</code> -> zrušení cyklu
- <code>continue</code> -> přeskočí krok v daném cyklu
- je možné si cyklus pojmenovat a pak <code>break</code>nout ten správný cyklus

## nekonečný cyklus
```java
while(true) {
}
```
- potom se zastavuje pomocí <code>break</code>
