# Barevná hloubka
- ang. Color depth
- počet bitů použitých k reprezentaci barvy pixelu -> počet bitů na pixel
- čím víc bitů, tím víc barev
- počet barev = 2<sup>n</sup>, kde n je počet bitů
- **Používané barevné hloubky:**
  - **1 bitová barva** 
    - Monochromatická
    - 0=černá a 1=bílá
    - gravírování
  - **8 bitová barva** 
    - Gify
    - 256 barev
  - **16 bitová barva**
    - High Color
  - **24 bitová barva** 
    - True Color
    - jpeg, bmp
